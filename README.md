# Polo Canvas Editor — Polos-Project

Scaffold inicial basado en la especificación proporcionada.

Instalación:

```bash
npm install
```

Desarrollo:

```bash
npm run dev
```

Estructura creada en `src/` y `public/mockups`.

Siguientes pasos:
- Añadir las imágenes reales en `public/mockups`
- Ejecutar `npm install` para instalar dependencias
- Abrir http://localhost:3000 después de `npm run dev`
